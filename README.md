# Weather Forecast API 🌤️

Простой REST API сервис на платформе **ASP.NET Core**, который возвращает прогноз погоды. Проект демонстрирует базовую архитектуру веб-приложения, маршрутизацию и работу с HTTP-запросами.

## 🛠️ Технологический стек

* **Платформа:** .NET (ASP.NET Core Web API)
* **Язык:** C#
* **Тестирование API:** REST Client (файл `localhost.http`)
